# הסרגל · Sargel

סרגל צד לשולחן העבודה (Windows + Mac) לשליפה מהירה של טקסטים, קישורים, פרטי לקוחות וגישות.

- **ידית בצד המסך** — מעבירים את העכבר והסרגל נשלף; מתרחקים והוא נסגר. 📌 נועץ אותו פתוח.
- **טאבים** — כל טאב הוא "מחסנית": נושאים ומיילים, לקוחות, גישות, קישורים… (גוררים כדי לסדר).
- **פריט** — לחיצה מעתיקה. פריט עם כמה שדות (טלפון, מייל, אתר, סיסמה) נפתח, וכל שדה מועתק בלחיצה.
- **חיפוש מהיר מכל מקום** — `Ctrl+Shift+Space` (ב-Mac: `Cmd+Shift+Space`), מקלידים, Enter מעתיק.
- **מוצפן** — הכל בקובץ `.sargel` אחד, AES-256-GCM, נעול בסיסמה ראשית. ננעל לבד אחרי חוסר שימוש.
- **אישי + צוות** — כספת אישית, ובנוסף כספת צוות (קובץ נפרד בתיקייה משותפת עם סיסמת צוות).

## התקנה

את קבצי ההתקנה מורידים מעמוד **Releases** של ה-repo.

**Windows** — מריצים `Sargel-Setup-x.y.z.exe`. אם מופיע "Windows protected your PC": *More info → Run anyway* (התוכנה לא חתומה בתעודה בתשלום).

**Mac** — פותחים את `Sargel-x.y.z-mac.dmg` וגוררים את Sargel ל-Applications. בפתיחה הראשונה:
*System Settings → Privacy & Security* → למטה ליד "Sargel was blocked" → **Open Anyway**.
אחרי זה מופיע אייקון קטן בשורת התפריטים למעלה, והידית בצד המסך.

## מעבר בין מחשבים

1. במחשב הראשון: "סרגל חדש" → בוחרים תיקייה של **Google Drive / OneDrive / Dropbox**.
2. בכל מחשב נוסף: מתקינים → "יש לי כבר סרגל" → בוחרים את הקובץ `sargel-personal.sargel` מאותה תיקייה.

שינויים מסתנכרנים לבד (גם כשעורכים בשני מחשבים — הסרגל ממזג, לא דורס).
גיבוי יומי מקומי נשמר אוטומטית, ויש גם "גיבוי לקובץ" בהגדרות.

> ⚠️ אין דרך לשחזר סיסמה ראשית שנשכחה. הקובץ מוצפן — בלי הסיסמה אף אחד לא יכול לקרוא אותו, כולל אנחנו.

## כספת צוות

הגדרות → **חיבור כספת צוות** → יוצרים קובץ `sargel-team.sargel` בתיקייה משותפת בדרייב.
אנשי הצוות: מתקינים את הסרגל → הגדרות → חיבור כספת צוות → "הצטרפות לכספת צוות קיימת" → בוחרים את הקובץ + סיסמת הצוות.
ביצירת טאב בוחרים "רק אני" או "כל הצוות".

## למפתחים

```bash
npm install
npm start          # הרצה מקומית
npm test           # בדיקות הצפנה ומיזוג
```

**שחרור גרסה:** מעדכנים `version` ב-`package.json`, ואז:

```bash
git tag v0.1.1
```

```bash
git push origin main --tags
```

GitHub Actions בונה את קובץ ה-Windows ואת קובץ ה-Mac ומפרסם אותם ב-Releases. מחשבי Windows מתעדכנים לבד.

מבנה:
- `src/main.js` — חלונות, ידית, קיצור מקשים, מגש, IPC
- `src/vault.js` — הצפנה, קריאה/כתיבה, מיזוג בין מחשבים
- `src/renderer/` — ממשק הסרגל וחלון החיפוש
- `build/make-icons.ps1` — יצירת האייקונים
